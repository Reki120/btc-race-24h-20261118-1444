A BTC trading bot that races cbBTC/USDC minute by minute: slow 60-minute momentum, full-size, with a cooldown, a minimum hold and a take-profit, so it stays in cash unless the last hour's return is clearly up. Built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty, $250 in USDC.

## Run it

```sh
node main.ts
```

`main.ts` is a Node 22 program (erasable TypeScript) that speaks agent-fun/bars-replay/v1 on stdin/stdout: one reply per batch, deterministic — two runs produce identical action logs. Standard library only, plus the vendored kit shim in `vendor/makefun-bars.ts`.
